# SWYNEX – Task 1: AI Problem Design

## Project Title
AI-Based Suspicious LinkedIn Profile Detection

## 1. Problem Statement
LinkedIn users may encounter fake profiles or misleading information. This project proposes a system that analyzes selected profile characteristics and flags potentially suspicious profiles for further review.

## 2. Target Users
- Students searching for internships and jobs.
- Job seekers and working professionals.
- Recruiters reviewing professional profiles.

## 3. Data Source
The initial prototype will use a small dataset of fictional professional profiles. Features may include profile-photo availability, completeness of education and work details, and number of connections. Each sample will have a label: “Potentially Suspicious” or “Apparently Genuine.”

No private information or unauthorized personal data will be collected.

## 4. Proposed AI Approach
First, a simple rule-based baseline will be designed. If a suitable labeled dataset becomes available, a machine learning classifier may be tested later. The system will explain which indicators influenced its result.

## 5. Constraints
- The initial dataset will be small and fictional.
- Profile characteristics cannot prove that an account is fake.
- No private information or unauthorized LinkedIn scraping will be used.
- Incorrect predictions are possible.
- The system will support, not replace, human judgment.

## 6. Success Criteria
The proposed system will be evaluated using accuracy, precision, recall, false positives, false negatives, and the clarity of its explanations, where the available test data permits. Results will be reported honestly.

## 7. Expected Outcome
A beginner-friendly prototype design that demonstrates how AI concepts can help identify potentially suspicious professional profiles for further review.

## 8. Future Improvements
- Develop a Python-based interface.
- Experiment with suitable machine learning models.
- Use a larger, reliable and appropriately sourced dataset.
- Improve explanations and reduce incorrect flags.
